# Dylan Commuting Analysis

Part of [[Dylan]]. Full report: `commuting-analysis.html` in the project folder.

Commuting from Pebmarsh (CO9 2NA) to 8 Bishopsgate, costed on daily Anytime Day Return tickets (no season ticket in the first month).

| Route | Per day |
|---|---|
| Marks Tey (direct) | £60.80 |
| Colchester (fast) | £70.30 |
| Bures (branch line) | £70.80 |

- **Cheapest month:** Marks Tey, about £1,485, which is 60% of take-home pay
- **Renting a London room instead:** about £1,070–1,300 a month, so commuting costs more
- **Time:** commuting costs about 55 hours a month compared with living in London
- **Season ticket (for reference only):** brings Marks Tey down to about £750 a month

Rupert's rule for these figures: start from daily peak fares, and show discounts and season tickets only as reference.
