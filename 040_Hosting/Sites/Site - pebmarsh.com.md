# Site - pebmarsh.com

Rupert's own village site. Back to [[Hosting]].

- **URL:** https://pebmarsh.com (and www). About 2,500 visits a month.
- **Type:** WordPress 7.1.3 on [[DreamHost]], folder `~/www/pebmarsh/wp.pebmarsh.com`. The `~/www/pebmarsh/pebmarsh.com` folder was an old copy and has been archived.
- **Database:** `wp_pebmarsh_com` on `mysql.pebmarsh.com`.
- **Plugins:**
  - BoldGrid Easy SEO
  - BoldGrid Gallery
  - RSS Import
  - UpdraftPlus (update pending)
  - WP Google Maps (files went missing in July; reinstall it if maps are wanted)
  - WP Super Cache
  - WPForms Lite: the contact form
- **Theme:** kelly. Default themes twentytwentyfive and twentytwentyfour are also installed.
- **Users:** rupert.
- **Security:** hacked in June–July 2026 ([[Incident 2026-07 Malware]]) and again in October 2026 ([[Incident 2026-10 Backdoor]]).
