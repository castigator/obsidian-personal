**Purpose:** a word-for-word record of the WhatsApp conversation, built directly from screenshots
Rupert provides. This is a potential evidentiary record — **no summarising, paraphrasing, or
editing of message text.** Every entry below is transcribed exactly as it appears in the

**This is separate from the topical summary notes elsewhere in `correspondence/heather/`**, which
remain in place for quick topic lookup. This file is the raw record.

## How entries are built

- Each message: sender, exact text, timestamp (as shown in the screenshot), and read-receipt status
  if visible (✓✓ etc.) — only if legible in the image.
- Where a screenshot only shows a message preview/snippet (not the full text), that's noted
  explicitly rather than filled in from memory or inference.
- **Gaps are marked as gaps**, not silently skipped — e.g. `[gap — no screenshot covering this
  period]`, so the transcript never implies completeness it doesn't have.
- Media/image attachments shared in the chat are noted with a description of their visible
  content, plus delivery/read status and any emoji reaction, rather than skipped.
- Backfill starts from whatever screenshot Rupert can reach first going back in time; entries are
  inserted in chronological order as they're supplied, regardless of the order screenshots arrive.
- **Deleted messages are never removed from the transcript, only tagged.** If a message previously
  transcribed here is later found to be deleted (i.e. a subsequent screenshot shows a "this message
  was deleted" placeholder where it used to be), mark that entry `[DELETED — later removed from
  the chat, content preserved as originally transcribed]` rather than deleting the line. If a
  screenshot shows a deletion placeholder for a message never previously captured verbatim (no
  earlier screenshot had its content), log it as `[gap — message deleted before it could be
  transcribed, original content unknown]` rather than inventing or guessing content.
