#claude-session
## Claude Actions

Open action points across every Claude project in this vault. Each project keeps its own list in an `<Project> Actions` note inside its own folder (for example [[Finance Actions]] in `020_Finance/`). Tick items here or in the project note: both are the same checkbox. Sessions read their project's list at start and update it at `/close`. Items are tagged `#claude-action`, which keeps them out of the daily note. See [[Claude Activity]] for what has been done.

### Urgent: High Priority or due within a Week

```tasks
not done
tags include #claude-action
(priority is above medium) OR (due before in 7 days)
group by filename
sort by due
sort by priority
short mode
```

### All Open, by Project

```tasks
not done
tags include #claude-action
group by filename
sort by priority
sort by due
short mode
```

### Done in the Last Two Weeks

```tasks
done
tags include #claude-action
done after 14 days ago
group by filename
sort by done reverse
short mode
```
